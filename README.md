# Zylo Frontend

Monochrome fashion storefront and full-featured Admin ERP built with Next.js 14.

## Features
- **Storefront**: Pixel-accurate monochrome landing, collections showcase, detail views, responsive cart, and checkout with Nepali payment methods (COD, eSewa, Fonepay).
- **Admin ERP Suite**: Master product & variant matrix manager with WebP Image Studio, inventory tracking, purchase orders, VAT/IRD tax invoices, sales returns, and CMS pages.

## Getting Started

```bash
cd client
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001) for the storefront and [http://localhost:3001/admin/dashboard](http://localhost:3001/admin/dashboard) for the admin portal.
